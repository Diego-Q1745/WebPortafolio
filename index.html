ECOMARKET

Sistema de gestión para una tienda de productos ecológicos, desarrollado con Java y MySQL.

Aplicación de consola desarrollada con Java 17 y MySQL para gestionar una tienda de productos ecológicos. Aplica Programación Orientada a Objetos, arquitectura por capas, JDBC, PreparedStatement, CallableStatement y colecciones. Permite administrar clientes y productos, consultar categorías, registrar ventas, validar y actualizar el stock, y consultar reportes de inventario y ventas.
